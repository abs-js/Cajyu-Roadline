# Cajyu Roadline

A complete learning path to master **Cajyu**.

Cajyu is a clean programming language that transpiles to JavaScript.

## Chapters

| Chapter | Topic |
|---------|-------|
| [Chapter 1](./Chapter-1/) | Basics |
| [Chapter 2](./Chapter-2/) | Intermediate |
| [Chapter 3](./Chapter-3/) | Advanced Libraries |
| [Chapter 4](./Chapter-4/) | Bigger Projects |

## How to use

1. Install Cajyu: `npm install -g cajyu`
2. Go through each chapter in order
3. Run the examples with `cajyu run <file.cjy>`

Official language repo: https://github.com/abs-js/Cajyu
